1. PROJECT OVERVIEW
-------------------

Project:
Adaptive Session Security Manager (SSM) for wearable healthcare IoT.

Paper title:
Adaptive Session Resumption for Hybrid Post-Quantum Authentication in
Wearable Healthcare IoT

Core idea:
The project combines a hybrid post-quantum authentication mechanism with
adaptive session resumption.

A full authentication uses:
    Ed25519
    +
    ML-KEM-512

After a successful full authentication, later communication can use a
lightweight bounded resumption mechanism based on:
    HMAC / HKDF-derived session material
    gateway-side per-device state
    a resumption counter
    timeout / risk / failure conditions

The purpose is to avoid performing the expensive full post-quantum
authentication for every subsequent wearable communication event while still
forcing a fresh full authentication when the session should no longer be
trusted.

34. WHAT THE PROJECT DEMONSTRATES
---------------------------------

The research evaluates whether adaptive session resumption can reduce the
computational and communication cost of repeatedly performing hybrid
post-quantum authentication in a wearable healthcare IoT setting.

The project compares:

    Baseline:
        always perform full authentication

versus:

    Proposed:
        perform full authentication when required and use bounded session
        resumption for eligible subsequent events.

The evaluation is performed against real wearable healthcare sessions rather
than only synthetic traces.

The main reported reductions are:

    STRESS:
        compute     87.36%
        bandwidth   78.55%

    AEROBIC:
        compute     83.72%
        bandwidth   75.27%

    ANAEROBIC:
        compute     85.27%
        bandwidth   76.67%
